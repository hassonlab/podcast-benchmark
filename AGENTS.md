# Agent Instructions

Before making code changes, read `docs/overview.md` for a brief map of the important folders and files, and read `docs/decisions.md` to understand why the current architecture is organized the way it is.

When making changes to the wider codebase, update `docs/overview.md` and `docs/decisions.md` when those changes affect repository structure, important entry points, extension surfaces, or architectural intent. Keep both files brief and useful for future agents.
